# PicTitle

PicTitle is a Chrome extension that helps make saved images easier to find later. When a person chooses an image to download, the extension looks for descriptive text already associated with it, such as alt text or a nearby caption, and uses that context to create a more useful filename.

The extension is designed for a quick, user-initiated workflow from the image's context menu. It includes a setting for limiting filename length. The project is implemented as a browser extension and does not require a separate account or server for its core naming workflow.

PicTitle's source code remains private. A separate public repository contains its privacy statement.
